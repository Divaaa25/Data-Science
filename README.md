# GSE301 Python Project – Student Academic Performance Analysis System

## Project Overview

This project is part of the **GSE301: Data Science – Python Fundamentals** course requirement. It focuses on building a **console-based Student Academic Performance Analysis System** using core Python concepts learned in class.

The system stores, processes, and analyzes mock academic data for students in a department. It also provides an interactive menu that allows users to perform various operations such as viewing students, adding new records, checking graduation eligibility, and identifying top performers.

---

## Project Objectives

The main objectives of this project are to:

* Apply Python fundamentals in a real-world academic scenario
* Demonstrate proper use of data structures
* Implement conditional logic and error handling
* Build an interactive, menu-driven console application
* Write clean, readable, and well-structured Python code

---

## Features

The system provides the following features:

1. View all registered students
2. Add a new student record
3. Check eligibility for graduation
4. Find the top-performing student
5. Exit the system

Each feature is implemented using Python functions for modularity and clarity.

---

## Python Concepts Demonstrated

This project demonstrates the following Python concepts:

* Variable declaration and data types
* Lists, tuples, dictionaries, and sets
* Conditional statements (if, elif, else)
* Pattern matching using match-case
* Functions and return values
* Logical operators (and, or)
* Exception handling using try-except
* List slicing and indexing
* Set operations (union, intersection, difference)
* User input handling and type casting

## Graduation Eligibility Criteria

A student is eligible for graduation if:

* CGPA is **2.5 or above**
* There are **no outstanding courses**
* The student is **currently active**
